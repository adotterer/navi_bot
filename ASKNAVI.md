# Commands, Character Aliases & Related Characters (For Regular Users)

## ✅ Where You Can Use Commands
**Ask‑Navi Channel Only (unless you are a Moderator/Legend):**
- **!mu**, **!mu-notes** → Matchup notes
- **!mu-q**, **!mu-question**, **!muq** → Matchup questions
- **!q** → General questions
- **!sq** → Stats questions
- **!fdq** → Frame‑data questions

**Anywhere (anyone can use):**
- **!s**, **!stats** → Stat lookup
- **!fd** → Frame‑data lookup

## > Matchup (MU) Commands
**!mu <character>**
→ Generates full matchup notes vs the specified character.
Example: !mu falco

**!mu-q <question>**
→ Ask a specific matchup question in plain English.
Example: !mu-q How do I deal with Peach's turnips?

## > General Questions
**!q <question>**
→ Ask Navi a general question (Ask‑Navi channel only for regular users).
Example: !q How do I edgeguard Wolf?

## > Stats Commands
**!s <stat> <character>** or **!s <character> <stat>**
→ Look up a character stat (works anywhere).
Examples: !s gravity peach • !s peach gravity

**!sq <question>**
→ Ask a stats question (Ask‑Navi channel only for regular users).
Example: !sq Who has the fastest dash speed?

## > Frame Data Commands
**!fd <character> <move>**
→ Direct frame‑data lookup (works anywhere).
Examples: !fd mario fair • !fd zelda pivotgrab • !fd samus zair

**!fdq <question>**
→ Ask a frame‑data question (Ask‑Navi channel only for regular users).
Example: !fdq Is palu bair safe on shield?

### Move Shorthand (works with !fd / !fdq)
